# Security Policy

## Project Status

CampusConnect is currently under active development.

The project is still being built, and some features are currently implemented as frontend/demo functionality. Production-level security measures will be added as the backend and database are developed.

## Supported Versions

Since CampusConnect is still under development, only the latest version on the `main` branch is currently supported.

| Version         | Supported          |
| --------------- | ------------------ |
| Latest (`main`) | :white_check_mark: |
| Older versions  | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability or security-related issue in CampusConnect, please report it through the project's GitHub repository.

When reporting an issue, please include:

* A clear description of the vulnerability
* Steps to reproduce it
* The potential impact
* Any relevant screenshots or technical details

Please avoid publicly sharing sensitive information that could be used to exploit the vulnerability.

## Development Notice

CampusConnect is not currently intended for handling real sensitive or production data.

Current frontend/demo features such as authentication, registration, and recommendations are for development and demonstration purposes only.

As backend development progresses, additional security measures such as secure authentication, authorization, input validation, password protection, and database security will be implemented.
